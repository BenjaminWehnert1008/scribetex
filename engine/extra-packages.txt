# LaTeX packages added to the TeX Live tree before the package folder is built,
# on top of what the base tree (see engine.lock.json) already contains.
# One TeX Live package name per line, as "tlmgr install" takes it.
#
# The deploy workflow reads this file. A name that tlmgr does not know is
# reported as a warning in the workflow run and left out; the deploy goes on.
# The name of a .sty file is not always the name of its package: rotating.sty
# comes with "graphics" and upgreek.sty with "was", for example.
# Every package makes the site larger, fonts most of all, and GitHub Pages
# allows 1 GB in total. Nothing here is downloaded by a visitor until a
# document asks for it.
#
# Not possible in a browser, whatever is listed here: packages that run other
# programs (minted, svg, gnuplottex) and biber. biblatex works with
# \usepackage[backend=bibtex]{biblatex}.
